Smart Unit Converter

A simple Python program that converts common units of temperature, distance, and weight.

What it can do

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Convert kilometers to miles
* Convert kilograms to pounds
* Handle basic user input and invalid menu choices

How to run

Make sure Python is installed on your computer.

Open a terminal in the project folder and run: python converter.py

Then choose the type of conversion you want and follow the instructions.

Example:
Smart Unit Converter
--------------------
1. Temperature
2. Distance
3. Weight

What do you want to convert? 1
Enter the temperature: 25
Is this in Celsius or Fahrenheit? Celsius

25.0°C is 77.00°F
